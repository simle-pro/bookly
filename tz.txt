ТЕХНИЧЕСКОЕ ЗАДАНИЕ
Сайт для чтения книг и аудиокниг
=====================================

1. ОБЩЕЕ ОПИСАНИЕ
-------------------------------------
Веб-сайт на Django (MVT), где пользователи читают книги онлайн
и слушают аудиокниги. Две роли: автор и читатель.
Стек: Django 6.1 + SQLite + HTML/CSS. 

2. РОЛИ ПОЛЬЗОВАТЕЛЕЙ
-------------------------------------
- Регистрация: указать логин, пароль и выбрать роль
  (автор / читатель). Создаётся User + Profile с ролью.
- Читатель: смотрит книги, читает главы, слушает аудио,
  ставит рейтинг, пишет комментарии.
- Автор: всё то же + добавляет/редактирует/удаляет свои книги,
  загружает текст (txt) и аудио (mp3).
- Книгу редактирует только её автор.
-админ-может все 

3. МОДЕЛИ ДАННЫХ
-------------------------------------
Profile   - user (OneToOne), role (author / reader)
Book      - author, title, description, genre,
            cover (картинка, необязательно),
            audio (mp3, необязательно), created_at
Chapter   - book (FK), title, number, text
Rating    - book, user, value (1-5),
            unique(book, user) - одна оценка на пользователя
Comment   - book, user, text, created_at
BookmarkList - user, name (unique per user) - списки закладок,
            при регистрации создаются "Читаю" и "Прочитано",
            можно создавать свои
Bookmark  - list, book, unique(list, book) - книга в списке
Notification - user, book, chapter,
            text, is_read, created_at - сообщение
            «вышла новая глава»

Средний рейтинг книги = AVG по всем оценкам.

4. СТРАНИЦЫ И МАРШРУТЫ
-------------------------------------
/                        Главная: список книг + поиск по названию
/register/               Регистрация с выбором роли
/login/                  Вход
/logout/                 Выход
/book/<id>/              Страница книги:
                         - обложка, название, описание, жанр, автор
                         - рейтинг (звезды + среднее значение)
                         - кнопка «Читать»
                         - кнопка «Слушать» (если загружен mp3)
                         - комментарии: список + форма добавления
/book/<id>/read/         Читалка: слева список глав,
                         справа текст главы, переходы <- ->
/book/<id>/listen/       Плеер: <audio controls> с mp3 книги
/book/<id>/rate/         POST: поставить оценку 1-5
/book/<id>/comment/      POST: добавить комментарий
/author/                 Кабинет автора: список своих книг
/author/book/add/        Добавить книгу (поля + txt + mp3)
/author/book/<id>/edit/  Редактировать книгу и главы
/author/book/<id>/delete/ Удалить свою книгу

/profile/               Профиль: аватар, роль, статистика
                         (закладки, списки, оценки, комментарии,
                         книги - для автора), последние комментарии
/bookmarks/             Мои закладки: списки с книгами,
                         создание своего списка, удаление списка,
                         убрать книгу из списка
/bookmarks/add/<id>/    Добавить книгу в выбранный список (POST)
/bookmarks/<id>/remove/ Убрать книгу из списка (POST)
/notifications/         Сообщения: новые главы по книгам
                         из закладок, отметить всё прочитанным

5. ЗАГРУЗКА  -> ГЛАВЫ
-------------------------------------
При загрузке .txt файла текст режется по строкам-маркерам:
"Глава 1", "Глава ...", "# ..." - каждая часть становится
отдельной главой (Chapter). Если маркеров нет - создаётся
одна глава "Книга". Главы можно добавлять и править вручную
в кабинете автора.

6. АУДИО
-------------------------------------
К одной книге загружается один mp3-файл. На странице книги
рядом с кнопкой «Читать» находится кнопка «Слушать»,
ведущая на страницу плеера.

7. РЕЙТИНГ И КОММЕНТАРИИ
-------------------------------------
- Рейтинг: звезды 1-5, ставит только залогиненный пользователь,
  может изменить свою оценку. Среднее отображается на странице книги.
- Комментарии: текст + автор + дата, видны всем под книгой,
  писать может только залогиненный пользователь.

8. ПОРЯДОК РАЗРАБОТКИ
-------------------------------------
1) Настройка проекта (INSTALLED_APPS, MEDIA, templates)
2) Модели + миграции + admin
3) Авторизация (регистрация с ролью, вход, выход)
4) CRUD автора (книги, главы, txt, mp3)
5) Список книг + поиск
6) Страница книги (детали, рейтинг, комментарии)
7) Читалка по главам + плеер
8) Обработка рейтинга и комментариев

9. ОГРАНИЧЕНИЯ
-------------------------------------

10. ДОПОЛНИТЕЛЬНЫЕ ФУНКЦИИ
-------------------------------------

10.1 ЗАКЛАДКИ (/bookmarks/)
- Две модели: BookmarkList (список закладок пользователя)
  и Bookmark (книга в списке).
- При регистрации автоматически создаются списки
  «Читаю» и «Прочитано».
- Пользователь может создавать свои списки (название).
  Дубликаты названий запрещены.
- Страница закладок: все списки с книгами, создание
  нового списка, удаление списка, убрать книгу из списка.
- На странице книги: выбрать список из выпадающего списка
  и нажать «Добавить». Показывается, в каких списках
  книга уже есть, можно убрать (кнопка «✕»).
- Каждый список принадлежит только своему пользователю
  (чужие не видны и не удаляются).

10.3 СООБЩЕНИЯ / УВЕДОМЛЕНИЯ (/notifications/)
- Модель Notification: пользователь, книга, глава (необяз.),
  текст, прочитано/нет, дата.
- Логика: когда автор добавляет новую главу (вручную
  или загрузкой txt), всем пользователям, у которых эта
  книга стоит в закладках (в любом списке), создаётся
  сообщение: «Вышла новая глава «...» в книге «...»».
- Автору книги сообщение НЕ приходит.
- Страница сообщений: список, непрочитанные подсвечены
  (оранжевая полоса + точка), ссылка ведёт на чтение
  этой главы. Кнопка «Отметить всё прочитанным».
- В шапке сайта - ссылка «Сообщения» с красным счётчиком
  непрочитанных (context processor).

11. ТЁМНАЯ ТЕМА И РЕЖИМЫ ЧТЕНИЯ (дополнено)
-------------------------------------

11.1 ТЁМНАЯ ТЕМА
- Кнопка 🌙/☀️ в шапке (рядом с бургером).
- Тема переключается через атрибут data-theme на <html>
  и CSS-переменные (светлая/тёмная палитра).
- Выбор сохраняется в localStorage, при заходе применяется
  сразу (скрипт theme.js в <head> — без мигания).
- По умолчанию — системная тема ОС (prefers-color-scheme).

11.2 ЗАГРУЗКА DOCX
- Форма загрузки принимает .txt и .docx (до 5 МБ).
- .docx парсится без библиотек: zipfile + xml.etree читают
  word/document.xml, абзыцы склеиваются в текст.
- Дальше текст режется на главы как обычно
  («Глава 1…», «# …»).
- Проверки: расширение, размер, валидный zip с
  word/document.xml; ошибки показываются в форме,
  книга при ошибке НЕ создаётся.

11.3 РЕЖИМЫ ЧТЕНИЯ
- На странице читалки переключатель:
  «📑 По главам» / «📜 Сплошной».
- По главам: текущее поведение (одна глава, ← →).
- Сплошной: все главы на одной странице, сверху
  название книги, слева содержание с якорными
  ссылками (#ch-<id>), заголовки глав.
- Режим в URL: ?chapter=<id> или ?mode=all;
  неизвестный mode откатывается в «по главам».
